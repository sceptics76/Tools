# Tools

Small browser tools. Each one is a self-contained web page in its own folder, with no build step and nothing to install.

| Tool | What it does |
| --- | --- |
| [Org Chart Builder](OrgchartBuilder/) | Build an org chart with names, roles and departments. Drag to arrange, paste a list, export to PNG, SVG or CSV. |

## Using a tool

- **Online:** if GitHub Pages is turned on for this repo, open `https://<your-username>.github.io/Tools/` and pick a tool.
- **Offline:** download the repo and open a tool's `index.html` in your browser.

## Adding a new tool

1. Create a folder named after the tool, in PascalCase (for example `InvoiceMaker/`).
2. Put the page in `index.html` inside that folder, plus a short `README.md`.
3. Add a row to the table above and a card to the root `index.html`.
